BACKGROUND
==================================================

The project is evaluating GTFS-Realtime as a possible complementary source to
MDD/TRIAS.

The current public GTFS.de realtime endpoint under investigation is:

https://realtime.gtfs.de/realtime-free.pb

The S18 feasibility audit covers the CURRENT feed and lifecycle behavior.

S19 has a different purpose:

Determine whether historical GTFS-Realtime point-in-time evidence from
approximately 3 months and 6 months ago is publicly retrievable for this exact
feed URL.

IMPORTANT:

The current GTFS-RT endpoint is a live stream.

Do NOT invent a date query parameter.

Do NOT assume that a URL such as:

...?date=2026-06-26

or any guessed archive path exists.

No official gtfs.de historical GTFS-RT archive endpoint has been established
by the project.

The audit must therefore distinguish:

1. current provider stream;
2. official/provider historical archive, if one can be documented later;
3. third-party archive snapshots;
4. catalog metadata;
5. continuous historical datasets.

These are NOT interchangeable.

==================================================
CRITICAL SEMANTIC DISTINCTION
==================================================

A historical snapshot is not the same as historical coverage.

For example:

one valid archived protobuf captured on 2026-06-26

means:

POINT-IN-TIME HISTORICAL SNAPSHOT EXISTS

It does NOT mean:

THREE MONTHS OF GTFS-RT HISTORY EXISTS

Likewise:

one snapshot from 2026-03-26

does NOT establish six months of continuous operational history.

Continuous history would require sufficiently dense archived snapshots over a
defined period.

This S19 audit must NOT claim continuous historical coverage.

PART 4 — WAYBACK ACCESS MODEL
==================================================

Use the Internet Archive CDX API only for archive discovery.

Search the EXACT original URL:

https://realtime.gtfs.de/realtime-free.pb

For each requested historical horizon:

- define target UTC date;
- search a bounded window around the target;
- default:

Thus the default window is:

target date - 7 calendar days
through

Do not automatically expand the search window.

The user can explicitly choose a different window later.

CDX queries must be bounded.

Request only metadata fields needed for selection, for example:

statuscode
mimetype
digest
length

Avoid retrieving thousands of rows.

Use a reasonable maximum such as 100 CDX rows per horizon.

Do not use infinite pagination.

No retries.

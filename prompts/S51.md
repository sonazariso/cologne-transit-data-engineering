## 1. Fix the incorrect pre-adapter THIS-call filtering

In:

`scripts/stage_09_source_backed_acceptance.py`

the current code filters raw Stage 8 bundle records using logic equivalent to:

```python
record.get("source_attributes", {}).get("selected_call_scope") == "THIS"
```

This is incorrect.

A raw Stage 8 `stop_event_observation` contains:

```text

```

with individual call records containing:

```text
call_scope = THIS / PREVIOUS / ONWARD
```

but the raw Stage 8 stop-event record does **not** contain:

```text
source_attributes.selected_call_scope
```

That attribute is added later by:

```python

```

Therefore the live probe discarded all real records before the adapter had a chance to select the THIS call.



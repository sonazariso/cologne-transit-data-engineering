# Failure behavior

Use the approved classifications.

At minimum:

- `SUCCESS`
- `SCHEDULED_SLOT_SKIPPED_OVERLAP`
- `AUTHENTICATION_OR_AUTHORIZATION_FAILURE`
- `RATE_LIMIT_RESPONSE`
- `HTTP_ERROR`
- `NETWORK_OR_DNS_FAILURE`
- `TIMEOUT`
- `PARSER_FAILURE`
- `PILOT_PERSISTENCE_FAILURE`
- `MDD_APPLICATION_ERROR`

Rules:

- 401/403 → stop immediately, zero retry
- 429 → stop immediately, zero retry
- network/DNS failure → record failure; later scheduled slot may continue
- timeout → record failure; later scheduled slot may continue
- HTTP 408 / relevant 5xx → record failure; no retry
- three consecutive failed request slots → terminate pilot
- a successful request resets consecutive-failure count

Never convert missing collection evidence into transport/service conclusions.

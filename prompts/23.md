==================================================
IMPORTANT DISCOVERY TO VERIFY
==================================================

GTFS-Realtime protobuf defines:

optional Cause cause = 6 [default = UNKNOWN_CAUSE]

and:

optional Effect effect = 7 [default = UNKNOWN_EFFECT]

Therefore:

reading:

alert.cause

or:

alert.effect

does NOT by itself prove that those fields were serialized by the producer.

The Python protobuf API must use:

alert.HasField("cause")
alert.HasField("effect")

to distinguish:

FIELD EXPLICITLY PRESENT

from:

FIELD ABSENT, DEFAULT VALUE RETURNED

This distinction is mandatory.

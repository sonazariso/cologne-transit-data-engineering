4. RecordedAtTime has not been observed in the tested MDD responses.
5. Historical MDD StopEvent queries at 1, 7 and 30 days returned timetable data but no realtime/actual timing.

GTFS-RT OFFICIAL SEMANTIC GUARDRAIL

The official GTFS-Realtime specification must be treated carefully:

- TripUpdate describes realtime progress/predictions for a trip.
- StopTimeUpdate may describe future events and, in some cases, past events.
- StopTimeEvent.time is explicitly defined by GTFS-RT as an
  "estimated or actual event as absolute time".
- Therefore:
    StopTimeEvent.time != automatically ActualTime.
- The schema itself does NOT provide a simple universal flag saying:
    "this StopTimeEvent.time is confirmed actual arrival".
- A past stop retaining a time does NOT by itself prove that the time is actual.
- A time becoming stable after the event does NOT by itself prove actual arrival.
- TripUpdate.timestamp is the moment realtime progress was last measured/updated for prediction purposes; it is not an arrival time.
- FeedHeader.timestamp is feed production timestamp; it is not an arrival time.
- Never infer actual physical arrival without explicit provider semantics or independent evidence.

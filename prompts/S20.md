2. MDD / TRIAS EVIDENCE TO PRESERVE
==================================================

The project has completed a detailed MDD/TRIAS source audit.

Validated semantic interpretation:

TimetabledTime
= scheduled/timetable time

EstimatedTime
= expected/predicted time

RecordedAtTime
= TRIAS semantic candidate for recorded/actual event time

EstimatedTimeLow / EstimatedTimeHigh
= optional prediction bounds when populated

PlannedBay
= planned platform/bay

EstimatedBay
= latest predicted platform/bay

SituationFullRef
= situation association, not proof of causality

NotServicedStop
= stop-level service status, not automatically whole-trip cancellation

Cancelled
= separate journey-level semantic where supplied

Important MDD evidence:

- live responses were successfully retrieved from the MDD /delfi endpoint;
- provider returned JSON despite XML/TRIAS request format;
- current realtime EstimatedTime is populated;
- RecordedAtTime was NOT observed in audited responses;
- historical 1-day, 7-day and 30-day StopEvent queries returned timetable data
  but no usable realtime/RecordedAtTime;
- 90-day and 180-day tests returned no matching historical event data;
- therefore retrospective MDD StopEvent cannot currently be relied on to
  reconstruct historical realtime observations.

Six live MDD lifecycle journeys were tested:

- 3 at Köln Hbf
- 3 at Köln Neumarkt

Across all six:

- the selected target remained observable around/after the event;
- no RecordedAtTime was observed in ThisCall, PreviousCall or OnwardCall;
- prediction evolution was observed in some journeys;
- no provider-wide claim was made that MDD never exposes RecordedAtTime.

Current MDD conclusion:

- useful and validated source for timetable/realtime prediction evolution;
- strong Cologne/VRS identity alignment;
- useful platform and Situation evidence;
- RecordedAtTime exists semantically in TRIAS but was not populated in bounded
  tests;
- confirmed Actual Time is therefore unavailable from tested MDD StopEvent
  data;
- prospective collection is required to preserve realtime evolution.

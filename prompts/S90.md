## RecordedAtTime is a hard acceptance requirement

Every source-provided RecordedAtTime occurrence must be persistable with:

- event/call context;
- arrival/departure context;
- observed snapshot;
- exact source path/lineage where available.

A later source NULL must never erase a previous non-NULL RecordedAtTime.

Preserve observation history append-only.

Support later analytical derivation of:

- LatestSourceRecordedAtTime;
- LastObservedRecordedAtTime;
- FirstObservedRecordedAtTime;

without overwriting source history.

Do not label RecordedAtTime as `ActualTime` in staging or collector code.

Do not convert missing RecordedAtTime to zero, scheduled time, estimated time, or observed time.

- `stg`
- `wrk`
- `dw`
- `analytics`

Do not create a new database.

Do not introduce PostgreSQL- or SQLite-style persistence concepts.

Where new persistence structures are needed, document for each:

- natural/source identity;
- primary key;

In particular, call/timing-history and multi-occurrence ServiceSection/Attribute evidence must preserve their own source occurrence grain.

## SQL transaction boundary

Persist one successfully parsed source response transactionally.

The SQL transaction must prevent partial persistence such as:

- stop observations inserted but situations missing;
- timing observations inserted but parent snapshot missing;
- Situation rows inserted without required links;
- CollectorRun marked succeeded while persistence failed.

Collector audit must reflect the real outcome.

Persistence failure must not be reported as collection success.

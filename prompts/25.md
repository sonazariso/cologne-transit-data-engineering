==================================================
USER DECISION — TIMING SEMANTICS
==================================================

The user has explicitly decided that future persistence must keep:

RecordedAtTime

and:

EstimatedTime

as completely separate concepts.

This is a non-negotiable semantic invariant.

RecordedAtTime must NEVER be derived from EstimatedTime.

EstimatedTime must NEVER be copied into RecordedAtTime.

The last observed EstimatedTime must NOT be treated as an actual time.

Collector observation time must NOT be stored as RecordedAtTime.

==================================================
THREE DISTINCT TIMESTAMPS
==================================================

The architecture must preserve three independent concepts:

1. TimetabledTime

Source-provided scheduled/planned event time.

2. EstimatedTime

Source-provided prediction.

This may change repeatedly across observations.

3. RecordedAtTime

Source-provided recorded/actual event time.

Only populate this when the source explicitly supplies RecordedAtTime.

If the source never provides it:

RecordedAtTime remains NULL.

Never synthesize it.

Additionally preserve:

ObservedAt / CapturedAt

This is the Collector's own timestamp indicating when a source response was
observed.

ObservedAt is NOT RecordedAtTime.

==================================================
RECORDED TIME CAPTURE CONTRACT
==================================================

When a non-null source RecordedAtTime is observed:

preserve the exact source value.

Also preserve the Collector observation timestamp at which it was first seen,
conceptually:

RecordedAtTime
RecordedAtTimeObservedAt

The disappearance of the event from a later source response must never erase
the previously observed RecordedAtTime.

A later NULL must never overwrite a previously captured non-null
RecordedAtTime.

Do not implement a fake fallback.

Forbidden fallbacks include:

RecordedAtTime = EstimatedTime
RecordedAtTime = last EstimatedTime
RecordedAtTime = TimetabledTime
RecordedAtTime = ObservedAt
RecordedAtTime = disappearance time

ESTIMATED TIME HISTORY CONTRACT
==================================================

EstimatedTime is analytically important and must remain independent because
the project intends to compare historical predictions against an eventual
RecordedAtTime.

Do not design future persistence around only the latest EstimatedTime.

The future observation model must preserve estimate evolution.

Conceptual example:

ObservedAt 10:00
EstimatedTime 10:18

ObservedAt 10:05
EstimatedTime 10:20

ObservedAt 10:10
EstimatedTime 10:22

RecordedAtTime 10:21:47

This must later support analyses such as:

- first estimate vs RecordedAtTime

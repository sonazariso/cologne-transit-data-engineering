## 4. Implement explicit reporting semantics for RecordedAtTime

Provide a read-only reporting projection/helper/view that distinguishes:

### Latest source state

`LatestSourceRecordedAtTime`

This represents RecordedAtTime in the newest observation of that source event.

It may legitimately be NULL.

### Last observed non-null value

`LastObservedRecordedAtTime`

This represents the most recently observed non-null source RecordedAtTime across the event's append-only history.

A later NULL must not erase it.

Also expose lineage:

- LastObservedRecordedAtTimeObservedAt
- LastObservedRecordedAtTimeSnapshotId
- LastObservedRecordedAtTimeAuditId
- source path
- count of non-null RecordedAtTime observations
- first observed non-null RecordedAtTime
- first observed non-null RecordedAtTimeObservedAt

Use names containing `RecordedAtTime`.

Do not use `ActualTime`.
